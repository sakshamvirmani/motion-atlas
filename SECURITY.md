# Security policy

## Supported version

Security fixes target the current `main` branch and the live Motion Atlas
deployment. Older commits and forks are not separately maintained.

## Report a vulnerability

Use this repository's private **Report a vulnerability** flow on GitHub. Include
the affected route or commit, reproduction steps, likely impact, and the
smallest safe proof needed to understand the issue.

Do not put credentials, personal learner data, active exploit details, or
account identifiers in a public issue. For ordinary bugs without sensitive
impact, use the normal issue tracker.

Motion Atlas will acknowledge a useful private report, investigate it, and
coordinate a fix and disclosure appropriate to the risk. No bounty program is
currently promised.
